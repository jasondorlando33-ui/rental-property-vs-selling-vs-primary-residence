# rental-property-vs-selling-vs-primary-residence
The script was created using python in JupyterLab. 

Goal:
This script aims to compare the financial outcome of selling a property, using it as a rental property, or a primary resident. 

Use:
-The script is dynamic and the initial variables can be adjusted to accurately compare for a given property.
-The default output is a dataframe and a graph.
-Obviously there are assumptions in how things are calculated like constant appreciation and maintenance cost.
-There are others assumptions that are less realistic but useful for modeling such as steady rent growth, which would certainly not be the case under normal lease conditions.
-This script should serve as a fairly accurate estimate, but for comparisons that are very close it may require a caveat due to assumptions.
